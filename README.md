## Designed and verified in simulation

- [emb-drone-flight-stack](https://github.com/CGainsWorks/emb-drone-flight-stack): six-layer STM32 flight controller designed to fabrication-ready Gerbers, with C++ firmware written from scratch and verified by host tests, software-in-the-loop simulation and an emulated MCU
- [emb-neurotech-prosthetic-arm](https://github.com/CGainsWorks/emb-neurotech-prosthetic-arm): six-axis myoelectric arm with sEMG front end, firmware, kinematics and a ROS 2 control stack
- [fpga-pmsm-foc-controller](https://github.com/CGainsWorks/fpga-pmsm-foc-controller): VHDL field-oriented motor control coprocessor, simulation-verified
- [ros2-diffdrive-nav-sim](https://github.com/CGainsWorks/ros2-diffdrive-nav-sim): differential-drive ROS 2 autonomy stack in Gazebo, comparing Pure Pursuit and Stanley path tracking against ground truth
- [plc-cip-batch-control](https://github.com/CGainsWorks/plc-cip-batch-control): IEC 61131-3 Structured Text controller for a clean-in-place skid
- [drone-mission-control-px4-sitl](https://github.com/CGainsWorks/drone-mission-control-px4-sitl): inspection-drone mission control in PX4 SITL (EKF, MPC vs PID, MAVLink)
- [ros2-industrial-arm-cell-sim](https://github.com/CGainsWorks/ros2-industrial-arm-cell-sim): vision-guided grasping and collision-aware motion with MoveIt 2
- [ros2-tello-navigation](https://github.com/CGainsWorks/ros2-tello-navigation): GPS-denied indoor drone navigation against a simulator and a Tello emulator
